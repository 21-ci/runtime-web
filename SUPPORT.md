# Support

| You want to | Go to |
|---|---|
| install, configure or run an instance | the docs: https://21-ci.github.io/runtime-web/ (start with [Install](https://21-ci.github.io/runtime-web/getting-started/install/)) |
| fix a failing install or a runtime problem | [Troubleshooting](https://21-ci.github.io/runtime-web/troubleshooting/) |
| ask a question or share an idea | [GitHub Discussions](https://github.com/21-ci/runtime-web/discussions) |
| report a bug | an [issue](https://github.com/21-ci/runtime-web/issues/new) with the Runtime Web version (`/healthz` reports it), the steps to reproduce and the relevant log lines with secrets removed |
| propose a feature | an [issue](https://github.com/21-ci/runtime-web/issues/new) that describes the problem you want solved |
| report a vulnerability | **not** an issue: follow [SECURITY.md](SECURITY.md) |
| run the node itself | the 21 Cloud Runtime support channels: [21-ci/runtime](https://github.com/21-ci/runtime) and its [SUPPORT.md](https://github.com/21-ci/runtime/blob/main/SUPPORT.md) |

Support is best effort from the maintainers and the community. Only the latest minor release gets fixes (see the
supported versions in [SECURITY.md](SECURITY.md)), so check that a bug still reproduces on it before you report it.
