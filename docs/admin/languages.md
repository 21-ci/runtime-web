# Languages

The console is available in English, Russian (Русский) and Uzbek (Oʻzbekcha, Latin script).

## Choosing a language

- **Signed in**: open the account menu (your avatar, top right) and pick a language under **Language**.
- **Sign-in, setup and invite pages**: use the language list below the form.

The choice is saved in the browser, so it applies to every account signed in from that browser and stays after
signing out. Without a saved choice, the console uses the first supported language from the browser settings,
and English otherwise.

## What is translated

Menus, pages, dialogs, messages and dates, numbers and sizes (for example `1,5 МиБ` or `5 мин назад`). Names
you enter, such as app, project and organization names, and technical values such as slugs, URLs, logs and code
are shown as they are.

Error messages from the server are shown in the chosen language when the console knows the error; otherwise
the server's English message is shown.

While the translation is being completed, some pages may still show English text.

To help translate, see [Translations (i18n)](../contributing/i18n.md).
