# Code style — Runtime Web

Every implementer must read this. It is taken from the owner's other repos (controller, tunnel, 21cli,
dashboard2.0, runtime).

## Go
- Go **1.26**. Module `github.com/21cloud/runtime-web`. Binaries live in `cmd/<name>/main.go`, code in
  `internal/<domain>/`. No `pkg/`.
- Use the stdlib first: `net/http` 1.22+ pattern routing (`mux.HandleFunc("GET /api/orgs/{org}", h)`), and no
  router framework.
- Logging uses `log/slog` (JSON handler in prod, text in dev; `LOG_LEVEL`).
- Errors are wrapped as `fmt.Errorf("pkg: what: %w", err)`: lowercase, prefixed with the package name. Sentinel
  errors are `var ErrX = errors.New("pkg: x")`. HTTP handlers map errors to `{"error":{"code","message"}}`, with
  codes in snake_case (same as the runtime).
- Config comes from env vars in UPPER_SNAKE, loaded once into a `config.Config` struct in `internal/config`.
  Use no viper.
- Use no ORM. SQL lives in `internal/store/queries/*.sql`, with code generated by `sqlc` and goose migrations in
  `internal/store/migrations/NNNN_name.sql`.
- Tests use stdlib `testing` only (**no testify**), with table-driven `for _, tt := range tests` and
  `t.Run(tt.name, …)`. Use `httptest` for HTTP. Integration tests run against `runtimetest.NewServer(t)` (the
  fake runtime) and an in-memory SQLite. Helpers call `t.Helper()`.
- Format and lint with `gofmt -l` (empty) + `go vet ./...`. No golangci.
- Makefile targets: `help build test vet fmt fmt-check web web-test e2e ci clean`, with `## help` comments and
  version ldflags `-X main.version/commit/date`.
- Dockerfile: multi-stage, `golang:1.26-bookworm` builder with BuildKit cache mounts,
  `CGO_ENABLED=0 -trimpath -ldflags="-s -w"`, running on `gcr.io/distroless/static-debian12`.

## Frontend (`web/`)
- **npm** (package-lock.json). Vite + React 19 + TS strict + Tailwind v4 (`@tailwindcss/vite`).
- Use shadcn-style primitives in `src/components/ui/` (lowercase files: `button.tsx`), built on Radix +
  `cva` + `clsx` + `tailwind-merge` (`cn()` in `src/lib/utils.ts`). Icons come from `lucide-react` and toasts
  from `sonner`. Theme uses CSS variables on `:root` plus a `.dark` class.
- Folders: `src/routes/` (TanStack Router file routes), `src/components/{ui,layout,features/<feature>}`,
  `src/lib/` (api client, utils), `src/hooks/`.
- Data goes through TanStack Query hooks only (`useApps(org)`), never `fetch` in components. The API client in
  `src/lib/api.ts` sends `credentials: "include"` and `X-CSRF-Token`.
- Lint uses an ESLint flat config (`eslint.config.mjs`, typescript-eslint + react-hooks); there is no Prettier.
- Tests: Vitest + Testing Library for components and hooks (MSW for the API). Playwright e2e lives in `e2e/`.

## Repo
- Commits follow Conventional Commits with a scope: `feat(auth): …`, `fix(router): …`, `test(authz): …`,
  `docs(plan): …`.
- `.env.example` has a header (`cp .env.example .env && docker compose up`), numbered sections, `dev-insecure-*`
  placeholders and a "Before production" block.
- `CLAUDE.md` has a module map table (Dir | Responsibility) plus build/test commands.
- The UI says **App**, never "val". The runtime's word "service" appears only in `internal/runtime`.
